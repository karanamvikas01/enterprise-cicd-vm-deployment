# Interview Notes

## Project Summary

Designed and implemented an enterprise Continuous Integration (CI) pipeline on AWS using Jenkins, Maven, SonarQube, Nexus Repository, GitHub, and Java.

---

## Key Responsibilities

- Configured Jenkins
- Integrated GitHub
- Configured Maven Builds
- Integrated SonarQube
- Configured Quality Gates
- Configured Nexus Repository
- Managed Jenkins Credentials
- Automated Artifact Publishing

---

## Interview Questions

### Why Jenkins?

To automate the build, test, analysis, and artifact publishing process.

---

### Why SonarQube?

To improve code quality by identifying bugs, vulnerabilities, and code smells.

---

### Why Nexus?

To store versioned build artifacts for future deployments.

---

### Why Quality Gates?

To prevent low-quality code from progressing through the CI pipeline.

---

### Why Maven?

To manage dependencies and automate the Java build lifecycle.
